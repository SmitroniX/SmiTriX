# SmiTriX

**Free, ad-free, open-source gym tracker for Android, iOS, Wear OS, and Web** — built & maintained by **Asmit Jogdand (SmitroniX)**.

- **Live Website & Interactive Demo** (no login required): https://smitronix.github.io/SmiTriX/
- **Android APK Releases**: https://github.com/SmitroniX/SmiTriX/releases/latest
- **Source Code**: https://github.com/SmitroniX/SmiTriX

## Highlights
- **470+ curated exercises** with crisp vector motion animations and interactive Male & Female anatomical body maps
- **Full workout engine**: live session timer, rest countdown & alarm, warm-up/drop/rest-pause sets, supersets, plate calculator, 1RM & progression tracking
- **Progress, History, Measures & Timeline**: 30-day volume sparklines, 4-palette consistency heatmap, muscle balance/fatigue/recovery maps, body measurements, progress photo timeline, and 3D spin medals
- **Nutrition & Recovery**: macro/water/supplement tracking, breathing & stretching recovery tools, training journal, gym passes, places, and AI plan import
- **Account Login & Cloud Sync (Mobile App)**: Firebase Auth (Email/Password sign-in, sign-up, password reset) with Cloud Firestore workout backup & sync — strictly for the native app; the website and web demo require zero login
